# FocusForge One

## Version

Prototype Alpha

## Mission

Help people focus without looking at a screen.

## Controls

Single Press
- Start
- Pause
- Resume

Double Press
- Skip to Break

Hold 3 Seconds
- Cancel Session

## States

Idle

Starting

Focus

Warning

Break

Finished

USB Powered

Startup Animation

25 Minute Timer

5 Minute Break

Progress Ring

Gentle Sounds
